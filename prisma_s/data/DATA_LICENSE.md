# Data & documentation licensing

Different materials in this repository carry different terms. Do not assume a
single licence covers everything.

## Adapted from a World Resources Institute publication — licence PENDING

- `keyword_dictionary_v1.3.csv` — the canonical keyword registry, adapted from
  **Table D-1** of the DCF supply-chain guidebook.
- `PRISMA_keyword_protocol_v1.1.md` / `PRISMA_keyword_protocol_v1.3.md` — the
  keyword-counting method, restated from the same guidebook.

Source:

> Wielgosz, B., dos Santos, A. B., Carter, S., Berger, A., Schneider, M.,
> Despontin, M., Immelman, J., Richter, J., Couto, A., Fitts, L. A., Gao, Y., &
> Dionizio, E. (in press). *Data for deforestation- and conversion-free (DCF)
> supply chain analyses: Applied learnings from soy in Brazil (Guidebook).*
> World Resources Institute.

WRI's default licences are **CC BY 4.0** for data/publications and **MIT** for
code ([Open Data Commitment](https://www.wri.org/data/open-data-commitment)).
However, WRI's [Permissions & Licensing](https://www.wri.org/research/permissions-licensing)
policy states that **co-authored** publications are frequently marked "All Rights
Reserved" and require a permissions request. This guidebook is co-authored, so
**its licence is treated as PENDING** until its published landing page states
one.

Consequently these files are **not offered under any licence by this repository
yet**. When the guidebook is published:

- if it is CC BY 4.0 — attribution must credit the work as shown on its wri.org
  page, link back to that page, and state that modifications were made;
- if it is not — a WRI permissions request is required before redistributing
  these files (or they must be removed).

See `DATA_PROVENANCE.csv` and `IP_HARDENING_PLAN.md` (portfolio) for the tracking
item. Datasets referenced by the guidebook may additionally carry their own
per-dataset terms — some non-commercial — under the
[WRI Data Platforms ToS](https://www.wri.org/about/wri-data-platforms-tos).
